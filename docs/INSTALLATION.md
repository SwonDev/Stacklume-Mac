# Instalar Stacklume para Mac

La aplicación es gratuita y el código propio tiene licencia MIT. Requiere Apple silicon y macOS 26 o posterior.

## Instalación sin certificado de Apple

Descarga el ZIP y su suma SHA-256 desde la release oficial. Comprueba la suma, descomprime y mueve Stacklume.app a Aplicaciones. La firma es ad hoc con Hardened Runtime, sin notarización. Si macOS bloquea la primera apertura, puedes autorizar solo esa app desde Ajustes del Sistema → Privacidad y seguridad → «Abrir igualmente», tras comprobar el origen. No desactives Gatekeeper globalmente.
